# Электронная маршрутная карта

Приложение для создания и ведения учета маршрутных карт плавок.

## Описание

Программа позволяет создавать электронные маршрутные карты, сохранять их и экспортировать в Excel.

## Требования

- Python 3.10+
- PySide6
- openpyxl

## Установка для разработки

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/form_marshrutka.git
cd form_marshrutka

# Установить зависимости
pip install -r requirements.txt
```

## Запуск

```bash
python marshrutka.py
```

## Сборка в EXE

```bash
# Установить PyInstaller
pip install pyinstaller

# Сборка
pyinstaller --windowed --icon=images/app.ico --add-data="specialists.json;." --name="Электронная_маршрутная_карта" marshrutka.py
```

Готовый exe-файл будет находиться в директории `dist/Электронная_маршрутная_карта`.

## Структура проекта

- `marshrutka.py` - основной файл приложения
- `specialists.json` - файл с данными специалистов
- `images/` - директория с изображениями и иконками
- `dist/` - директория с собранным приложением
- `Release/` - директория с готовым дистрибутивом

## Использование

1. Запустите приложение
2. Через меню "Файл" выберите нужное действие:
   - "Создать" - создание новой маршрутной карты
   - "Открыть" - открытие существующей маршрутной карты
   - "Сохранить" - сохранение текущей маршрутной карты
   - "Экспорт в Excel" - экспорт данных в формат Excel
